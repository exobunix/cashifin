# Cashify Admin Panel

This is the admin portal for the Cashify clone platform, built with **Next.js** and **Tailwind CSS**.

## Structure

*   `src/app/` - Next.js app pages (Dashboard, orders, management pages).
*   `src/components/` - Shared UI components.
*   `src/services/` - API calling hooks and integrations.
*   `src/store/` - Redux state management.
